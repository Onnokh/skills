---
name: browse
description: Do browser work in the user's Dia browser with browse (https://github.com/anomalyco/browse). Use when the user asks to open, read, click, or fill in a web page.
---

Use the `browse` MCP tools to do browser work in the user's Dia browser, where they are already logged in. browse shows Dia as "Chromium".

If the tools are not available, tell the user to run `browse install`.
